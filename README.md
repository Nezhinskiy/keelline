# keelline

**keelline has been renamed to [stayfixed](https://github.com/stayfixed/stayfixed).**

This package is a thin forwarder for the old name. Installing it installs `stayfixed`, and the
`keelline` command prints a one-line notice and then runs `stayfixed` with the same arguments, so
anything that still calls the old name keeps working. For new installs use the new name:

```bash
pip install stayfixed
```

- Project: <https://github.com/stayfixed/stayfixed>
- PyPI: <https://pypi.org/project/stayfixed/>
