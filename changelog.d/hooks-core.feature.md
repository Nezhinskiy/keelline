Keelline's hooks now fire in a real session. The plugin ships `hooks/hooks.json`, which both Claude Code and Codex read with no configuration, and a shell wrapper that finds a Python 3.11 or newer, runs from your project root, and refuses with a named reason rather than letting a broken guard read as permission. The dispatcher also remembers what it has already said, so a once-per-session notice arrives once instead of on every tool call.
