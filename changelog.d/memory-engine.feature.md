`keelline memory` gives an agent curated working memory: notes in Markdown with frontmatter, a `MEMORY.md` routing index generated from them rather than hand-maintained, and session-start bundles that arrive whole instead of truncated. Notes committed to a repository you cloned reach the model only after `keelline memory trust --in-repo-memory`, and then only inside a marked region that says they are data — change what the repository ships and you are asked again, and the harness's own link to the store is withdrawn until you do. A bundle too large for one session-start slot is withheld with a notice rather than delivered cut in half. In a git worktree the store is linked in rather than copied, so a note written from either side is the same note.
