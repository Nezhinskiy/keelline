Every list of names a repository or its history can make as long as it likes now names at most eight
of them and says how many more there are, with one exception: when only some of a memory store's
`memory.groups` resolve, `stayfixed memory refs` still gives every unresolved group's reason, one per
line inside the region it marks as data, under a line that counts them. On summary lines, `--json`
still carries every name: the documents `stayfixed docs trail` listed with no declared state; the
notes `stayfixed memory index` could not read and the notes or `memory.index_extra` pointers it held
back; the refused keys on `stayfixed gate`'s `config:` line; the custom gates `stayfixed assess
--builtin` left out; the gates `stayfixed adopt promote` promoted and those still advisory; the
offences `stayfixed commit check` found; and, in `stayfixed bugs check --json`, the files claiming one
identifier, each of which past the first also has a finding of its own. `stayfixed init`'s note on an
adopted `stayfixed.toml`'s custom gates named five before counting and now names eight, like the
rest. Refusals with no `--json` are bounded the same way: the `docs/trail.toml` `[states]` keys that
name no document, counted in full, the first eight in sorted order, with a note that a re-run after
updating those names the rest; the groups of a memory store none of whose `memory.groups` resolves,
counted, with the reasons for the first eight in sorted order; the gates a project runs, when
`[stayfixed] enforced` names one it does not; the unknown keys and sections of a `stayfixed.toml`; and
the merge bases that leave `stayfixed test attribute` undetermined. And a `[states]` key, a
`[[theme]]` label or a `memory.groups` entry longer than 120 characters is named in a refusal by its
first 120 characters and its length, where one key of 200 000 characters used to make a line of
200 000 characters.
