Keelline now carries the guards a session's shell needs, ready for the plugin's hook entries to invoke: a `PreToolUse` handler refuses a backgrounded command that would leak an `&` job past the harness's reap or begin with a `sleep` that returns at once, and advises when a command restores a backup on a line the shell may never reach. `keelline commit check` fails a pull request whose messages carry an AI attribution trailer, and `keelline commit strip` takes one out of a commit-message file — it is what the chained `prepare-commit-msg` hook runs, so the trailer is gone before the commit exists, and the hook keeps whatever hook the repository already had. `keelline test hygiene` names the two environment faults that make a red run unattributable, and `keelline test audit-entrypoints` lists tests that never exercise what they name.

The background-cleanup handler also advises when a backgrounded command ends in `; echo …`: the harness reports the exit code of the chain's last command, so the notification says 0 after the command before the echo failed — the hint names that command and says to read its status from the output it wrote.
