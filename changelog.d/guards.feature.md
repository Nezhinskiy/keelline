Keelline now carries the guards a session's shell needs, ready for the plugin's hook entries to invoke: a `PreToolUse` handler refuses a backgrounded command that would leak an `&` job past the harness's reap or begin with a `sleep` that returns at once, and advises when a command restores a backup on a line the shell may never reach. `keelline commit check` fails a pull request whose messages carry an AI attribution trailer, and the `prepare-commit-msg` hook that `keelline setup --git-hooks` installs strips the trailer before the commit exists, says so, and chains to whatever hook the repository already had. `keelline test hygiene` names the two environment faults that make a red run unattributable, and `keelline test audit-entrypoints` lists tests that never exercise what they name.
