Every file Keelline replaces in your repository is replaced atomically and keeps the permissions it had, so an interrupted run cannot leave an empty file where a note was. Paths are walked one component at a time and refuse to follow a symlink or to leave the project root, which means a repository cannot redirect a write by committing one. Your machine configuration file is `~/.config/keelline/config.toml` and is not selectable by a repository: neither `KEELLINE_CONFIG` nor `XDG_CONFIG_HOME` moves it, because a repository's own settings file could have set them. Pass `--machine` to read a different one.
