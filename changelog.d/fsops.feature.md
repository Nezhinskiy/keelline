Every file Keelline replaces in your repository is replaced atomically and keeps the permissions it had, so an interrupted run cannot leave an empty file where a note was. Paths are walked one component at a time and refuse to follow a symlink or to leave the project root, which means a repository cannot redirect a write by committing one. `KEELLINE_CONFIG` and `XDG_CONFIG_HOME` choose your machine configuration file only from an interactive shell — never from a hook, where a repository's own settings file could have set them.
