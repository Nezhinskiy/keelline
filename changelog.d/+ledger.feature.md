Keelline now carries a bug ledger: one Markdown file per bug under the directory your `keelline.toml` names, a generated index that is a pure function of those files, and `keelline bugs check`, which holds every entry to a flat frontmatter contract, every high-severity entry to a filled evidence-boundary line, and every identifier written anywhere under your code roots to an entry that exists. `keelline bugs new` files an entry with the next free number across every branch this checkout can see, and `keelline bugs renumber` moves one and takes every reference along, leaving a pointer at the old number so nothing written before the move points at nothing. Regenerating the index refuses to delete content it did not write. Before the first entry `bugs check` passes a project that cites none, and reports every citation of an entry file as dangling, so deleting the ledger never silences it.
