stayfixed now carries a bug ledger: one Markdown file per bug under the directory your `stayfixed.toml` names, a generated index that is a pure function of those files, and `stayfixed bugs check`, which holds every entry to a flat frontmatter contract, every high-severity entry to a filled evidence-boundary line, and every identifier written anywhere under your code roots to an entry that exists. `stayfixed bugs new` files an entry with the next free number across every branch this checkout can see, and `stayfixed bugs renumber` moves one and takes every reference along, leaving a pointer at the old number so nothing written before the move points at nothing. Regenerating the index refuses to delete content it did not write. Before the first entry `bugs check` passes a project that refers to none, and reports every mention of an identifier and every citation of an entry file as dangling; with `--base`, which the `bugs` gate passes, the ledger is compared with the commits the change forked from that base at, every merge base together: a ledger there that the tree lacks is a `ledger-removed` finding, and an entry there whose exact name the tree lacks is an `entry-removed` finding whatever still mentions it, so neither deleting the ledger, nor emptying it, nor renaming an entry in case silences the gate, while a branch behind its base is not blamed for an entry filed after it forked; a shallow clone, whose fork point can be cut off, is a gate that could not run: entries are append-only, and `bugs renumber` is how one moves.
