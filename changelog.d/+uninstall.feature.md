`stayfixed uninstall [--dry-run] [--force PATH]` takes back what `init` and `upgrade` wrote:
files whose bytes are still stayfixed's go, stayfixed's sections come out of files that hold
other text, the ledger goes, and every file you edited stays and is listed. It refuses
while `.stayfixed/local/` holds notes or edited files that its ignore block keeps out of
git, and while `stayfixed.toml` is missing but the manifest still records it, so the record of
what stayfixed wrote is never lost: restore the file and run it again. A `stayfixed.toml` you wrote
before `init` is left in place, and a note says so.
