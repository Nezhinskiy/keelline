Every area is again imported through its published `api.py` alone. `keelline memory
session-context` and `keelline doctor` had each reached into a private module of the hook area;
the names they needed — the harness discriminator and the hook sink's on-disk layout — are now
defined on `keelline.hooks.api`, which is where the vocabulary two areas share belongs. The
surfaces of `attach`, `overlay` and `setup` lost the names nothing imported, and each of the
four areas that shipped with the install path now has the test every older area had.
