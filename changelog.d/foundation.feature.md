Keelline installs as a Claude Code and Codex plugin and as a command-line tool — from a git reference until the first release tag exists, because `uv tool install keelline` has no version to resolve before then. It reads a committed `keelline.toml` under a shipped preset, dispatches the harness's hook events, and imports nothing outside the standard library at runtime, so a hook works wherever `python3` does.
