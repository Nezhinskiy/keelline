# Cross-project notes

Notes that are true across your projects: how you like to work, what you have learned about a
tool you use everywhere.

This directory is the store a bound repository links to as its `developer` group, alongside
that project's own notes under `projects/<name>/memory/`. The routing index a session reads is
rendered from both; it is generated, so write the notes and let the index follow.

A note that carries `metadata.startup` is a standing rule: it is injected in full at the
start of every session, ranked by that number. Your personal rules are notes of this kind, kept
here.

A note about one project goes under `projects/<name>/memory/` instead. Keeping the two apart
is what stops one client's work reaching another client's session.
