# Audit records

One file per audit that produced entries in this ledger: what was examined, over which
revision, with which method, and what the examination could not have seen. It is the
provenance a reader needs to weigh an entry that cites it — a finding is only as good as the
sweep that found it, and a sweep nobody described cannot be repeated or bounded.

Nothing here is read by a command. `keelline bugs check` judges the entry files and the
generated index; these records are for people, and the entries link to them by hand.
