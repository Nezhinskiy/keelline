# Personal standing rules

One Markdown file per rule. These are yours: they hold across every project you work on, and
they reach a session at its start rather than being looked up, because by the time a rule
would be looked up the decision it governs has already been made.

Rank a rule by giving it `startup` in its metadata. Ranked rules are injected first and are
the ones worth a session's attention budget; everything else waits to be asked for.

Write a rule as an instruction, not as the story of the day you learned it. "Ask before
rewriting a migration" is a rule; "remember the incident in March" is a memory. If a rule is
about one project only, it belongs in that project's directory under `projects/`, not here.
