# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] in full. Please read it
there rather than here, so that this file cannot drift out of step with the version it claims
to be.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: everyone taking part in this project's issues, pull requests, discussions and reviews
is expected to be respectful, to assume good faith, and to accept that technical disagreement is
normal and personal attacks are not.

## A note specific to this project

Keelline's reviews are direct. A finding will be stated as a finding, a disagreement about an
approach will be argued on its merits, and "this is wrong because X" is not rudeness. The line
is the usual one: criticise the code, the design or the argument — never the person who wrote
it, and never their competence, background or identity.

## Reporting

To report behaviour that breaks this code, open a private report through GitHub:

<https://github.com/Nezhinskiy/keelline/security/advisories/new>

That channel is private to the maintainers. It is meant for security reports, and using it for
a conduct report is a deliberate reuse until a dedicated contact address is published here —
say in the first line that it is a conduct report rather than a vulnerability.

Reports are handled confidentially. The maintainers will respond as promptly as a single-
maintainer project can, and will not discuss a report with anyone who does not need to know.

## Enforcement

The maintainers may edit, hide or delete comments, commits, issues and pull requests that break
this code, and may temporarily or permanently ban a contributor. Where a response is not
obvious, the Contributor Covenant's own enforcement ladder — correction, warning, temporary ban,
permanent ban — is the one used.
